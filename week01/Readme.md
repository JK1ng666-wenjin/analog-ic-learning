# Week 01 · RC 充电仿真

## 目的

1. 跑通 ngspice 仿真流程（网表 → 仿真 → 数据 → 图）；
2. 验证一阶 RC 电路的充电规律与时间常数 τ = RC。

## 电路与参数

- 电源：5 V 脉冲（上升沿 1 ns）
- 电阻：R = 1 kΩ
- 电容：C = 1 µF
- 时间常数：τ = RC = 1 ms

## 结果

| 时间 | 仿真值 | 理论值 5(1 − e^(−t/τ)) |
|---|---|---|
| 1 ms（1τ） | 3.16 V | 3.16 V（63.2%） |
| 3 ms（3τ） | 4.75 V | 4.75 V（95%） |
| 5 ms（5τ） | 4.97 V | 4.97 V（99.3%） |

![RC 充电曲线](rc_curve.png)

> 图由本人 ngspice 仿真数据绘制。

## 结论

1. **仿真与理论重合**：三个时间点的电压与 5(1 − e^(−t/τ)) 一致。
2. **τ 决定充电速度**：t = τ 时充到 63.2%，5τ 后基本充满。
3. **指数规律**：曲线斜率随时间递减，先快后慢。

## 复现

```bash
cd ~/ic/week01

```

## 踩坑记录

- `.tran 0 5m` 会报 TSTEP is invalid，时间步长不能写 0，改为 `.tran 1u 5m`；
- 批处理模式（-b）下不能用 plot 命令，改用 wrdata 导出数据、再用 Python 画图。
